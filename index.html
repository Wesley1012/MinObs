Добро пожаловать

📅 21 марта 2025 🏷️ #obsidian #старт ⏱️ 2 мин чтения

Это демонстрационная страница, оформленная в стиле Obsidian — приложения для заметок, основанного на локальных Markdown‑файлах.

Основные возможности

Интерфейс повторяет характерные черты десктопной версии:

  • Трёхпанельный макет: файлы — редактор — контекст
  • Тёмная тема с акцентным фиолетовым цветом
  • Вкладки документов и хлебные крошки
  • Стилизованные код‑блоки, цитаты и callout‑блоки
  • Внутренние ссылки и теги

Пример кода

Блок кода с подсветкой в духе Obsidian:

// Простой пример на JavaScript
function greet(name) {
  return `Привет, ${name}!`;
}

console.log(greet('Obsidian'));
💡 Совет. Используйте #теги для категоризации заметок и [[внутренние ссылки]] для связывания идей.

Заметки — это не просто записи. Это инструмент мышления, который помогает соединять идеи и находить неочевидные связи.
